# /04B-后端代码实现

## Goal

完成范围内的接口、服务、业务逻辑、数据访问、事务、消息和后端验证。

## Required Inputs

- `/04-代码实现` 的处理方式与开始条件结果
- 用户请求、现有后端行为、代码规范和本地代码
- 完整检查时：已确认的完成标准和相关技术方案

## Execution Rules

- 继承 `/04-代码实现` 的策略解析、分支与未提交改动检查、并行开发隔离、证据真实性和远程写入授权边界。
- 只有不改对外 API、数据结构、认证权限、迁移、部署或生产配置，且范围清楚、可本地回退的后端小改，才可继续轻量处理。
- 实现中发现任何对外 API 或协议、数据结构、认证权限、迁移、持续集成与部署流程（CI/CD）、生产配置、跨仓、不可逆操作或改动超出范围，立即停止轻量处理，重新解析策略并升级为完整检查。
- 不得通过改低测试阈值、改宽验收标准或删除测试来换取通过。
- 发现必须超出已确认范围才能完成时，不得静默扩大。

## Required Outputs

- 轻量处理：最终一次性记录修改的服务/模块、diff 审查和验证证据。
- 完整检查：更新 `features/{feature}/04B-后端代码实现.md` 与状态文件。
- 明确列出未完成的数据、依赖服务或环境检查。
