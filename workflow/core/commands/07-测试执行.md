# /07-测试执行

## Goal

验证改动：运行约定的测试、构建、运行态或人工步骤，如实记录每个验收项的结果与证据。

## Required Inputs

- 当前代码与完整 diff
- 轻量处理：当前任务中的验收项
- 完整检查：`features/{feature}/00-完成合同.md` 与测试记录

## Execution Rules

- 不修改验收标准、阈值或“必须通过”标记；不删除测试来换取通过。
- 只有真实执行过约定方法，才能记为“已通过”或“未通过”。证据包含命令、退出码、关键输出、当前 commit（如有）、截图或日志路径。
- 已通过后，相关代码或配置再次改动，结果改为“改动后需重查”并重新执行。
- “已确认跳过”只能记录用户的明确确认。
- 本命令本身不授权修改业务代码；需要修复时回到实现命令，并重新走完整 diff 审查后再验证。
- 远程 Git、发布、部署、数据库写入和生产配置写入需用户明确授权。

## Required Outputs

- 轻量处理：在终点摘要中一次性列出验证命令、结果、需人工确认项和明确卡点。
- 完整检查：更新 `features/{feature}/07-测试执行.md`、完成标准中的验收结果与 `00-工作流状态.md`。
- 说明当前证据是否足以支持合并或正式发布。

## 内部兼容详情

完整检查文件可保留 `Oracle`、`blocking`、`NOT_RUN/PASS/FAIL/STALE/WAIVED` 机器字段，默认对用户使用中文验收结果。
