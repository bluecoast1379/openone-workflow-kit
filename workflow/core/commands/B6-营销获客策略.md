# /B6-营销获客策略

## Goal

营销获客策略: 制定总体营销/获客策略——阶段判断、目标体系、主攻渠道组合、信息一致性、内容支柱和发布节奏。

## Required Inputs

- `AGENTS.md`
- `workflow/team-profile.yaml`
- Workspace-level `business/{product}/B1-业务定位.md` 到 `B5-渠道漏斗映射.md`
- `business/{product}/B7-营销预算.md`（如已存在，双向校准）

## Execution Rules

- Read local facts before writing conclusions.
- 策略必须先声明当前阶段（验证期 / 首发期 / 增长期），且与 `/B3-PMF与客户画像` 的 PMF 判定一致；未达 PMF 时不制定放大型投放策略。
- 主攻渠道选择必须引用 `/B5-渠道漏斗映射` 的评估结论，默认 1-2 个主攻 + 1 个实验渠道。
- 每个策略目标必须有可测指标和期限。
- 各渠道信息口径必须能追溯到 `/B1-业务定位` 的定位陈述，保持一句话价值主张一致。
- 默认使用简体中文展示工作流沟通和阶段产物；专有名词、产品名、品牌名、渠道名、代码标识符、命令、文件路径、API、SDK、框架、协议、标准和官方英文术语保留原文。
- 本阶段只产出策略文档，不授权修改业务代码；发布计划中的对外动作留待 `/B8-渠道执行策略` 生成清单并由用户授权或自行执行。

## Required Outputs

- Create or update workspace-level `business/{product}/B6-营销获客策略.md`.
- Update workspace-level `business/{product}/00-商业化状态.md`.
- Record unvalidated assumptions and evidence gaps explicitly.

## Suggested Structure

1. **阶段判断**：验证期（找 PMF）/ 首发期（launch）/ 增长期（放大已验证渠道），依据 B3 判定和当前数据。
2. **目标体系**：北极星指标 + 本周期漏斗目标（例如"90 天内自然注册达到每周 X"），含基线值。
3. **主攻渠道组合**：主攻渠道、实验渠道、放弃渠道；选择理由引用 B5 评估。
4. **信息架构**：核心定位语 → 各渠道 message 变体对照表；确保价值主张一句话在所有渠道一致。
5. **内容支柱与复用链**：3-4 个内容主题；一鱼多吃路径（长文 → 社媒帖 → 短视频/短帖 → 邮件）。
6. **发布节奏与里程碑**：launch 计划（如 Product Hunt、开发者社区首发、邮件列表）、每周营销例行动作、关键时间点。
7. **与研发轨联动**：策略需要的产品侧支持（埋点、分享钩子、推荐机制、试用引导），通过 `/new-feature` 进入研发轨。
