# /B7-营销预算

## Goal

营销预算: 确定金钱与时间双预算、各渠道分配与上限、CAC 目标和止损线，让个人开发者的营销投入可控可复盘。

## Required Inputs

- `workflow/team-profile.yaml`
- Workspace-level `business/{product}/B2-商业模式.md`（CAC 上限、毛利）、`B5-渠道漏斗映射.md`（渠道成本）、`B6-营销获客策略.md`
- 用户提供的可支配现金与时间约束

## Execution Rules

- Read local facts before writing conclusions.
- 个人开发者必须同时编制金钱预算和时间预算（每周营销小时数）；时间是最稀缺资源，必须显式计入。
- 每个渠道设月度上限和止损条件；预算超支或单渠道 CAC 连续超标必须触发 `/B9-策略复盘`，不得静默追加预算。
- 实验渠道预算与已验证渠道预算分开管理，写明比例和调整规则。
- CAC 目标必须由 `/B2-商业模式` 的单位经济推导，不得凭空设定。
- 默认使用简体中文展示工作流沟通和阶段产物；专有名词、产品名、品牌名、渠道名、代码标识符、命令、文件路径、API、SDK、框架、协议、标准和官方英文术语保留原文。
- 本阶段只产出预算文档，不授权任何实际支出、充值或投放动作；实际付费由用户执行。

## Required Outputs

- Create or update workspace-level `business/{product}/B7-营销预算.md`.
- Update workspace-level `business/{product}/00-商业化状态.md`.
- Record unvalidated assumptions and evidence gaps explicitly.

## Suggested Structure

1. **约束盘点**：每月可投入现金、每周可投入时间、机会成本说明（营销时间挤占的开发时间）。
2. **双预算表**：渠道 ×（金钱/月、时间/周、预期产出、止损线）。
3. **CAC 目标**：由 B2 推导的 CAC 上限、各渠道目标 CAC、混合 CAC 目标。
4. **实验与已验证分配**：实验预算 vs 已验证渠道预算比例（例如 30/70）及调整规则。
5. **追踪口径**：支出与时间的记录方式和存放位置，作为 `/B9-策略复盘` 的数据输入。
